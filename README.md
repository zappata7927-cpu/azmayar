# آزمـیار | مرجع آموزشی آزمایش‌های آزمایشگاهی

اپلیکیشن آموزشی برای دانشجویان و کادر درمان — به‌ویژه **پرستاران و پزشکان** — که بر پایه یک دیتابیس جامع آزمایش‌های تشخیصی و آزمایشگاهی ساخته شده است.

> **طراح و سازنده:** سید مجتبی کاظمی — عضو هیأت علمی گروه پرستاری، دانشکده علوم پزشکی بهبهان

---

## معماری فنی

- **Next.js 16 + TypeScript + Tailwind CSS 4** (رابط کاربری راست‌به‌چپ با فونت وزیرمتن)
- **PWA کامل:** manifest + Service Worker (کش آفلاین کامل شامل داده‌ها)
- بدون نیاز به سرور یا دیتابیس — همه داده‌ها فایل JSON استاتیک در `public/data/`
- ذخیره پیشرفت کاربر (مرور لایتنر، نتایج آزمون، علاقه‌مندی‌ها) در `localStorage` خود گوشی

```
دیتابیس Word (آزمایش‌های تشخیصی) → scripts/parse_lab_db.py → tests.json (۵۶۵ رکورد ساختاریافته)
                    → scripts/gen_cards_questions.py → cards.json + questions.json
                    → public/data/*.json → اپلیکیشن
```

## انتشار روی گیت‌هاب و نصب روی گوشی (بدون نیاز به هیچ نصب و کامپایل)

1. یک مخزن (Repository) جدید در گیت‌هاب بسازید (مثلاً با نام `azmayar`).
2. محتویات همین پروژه را در مخزن بالا بیاورید:
   ```bash
   git init
   git add .
   git commit -m "Azmayar v1.0"
   git branch -M main
   git remote add origin https://github.com/<نام‌کاربری‌شما>/<نام‌مخزن>.git
   git push -u origin main
   ```
3. در مخزن، به **Settings → Pages → Build and deployment → Source** بروید و مقدار آن را **GitHub Actions** بگذارید.
4. تمام! اکشن `deploy.yml` به‌صورت خودکار سایت استاتیک را می‌سازد و منتشر می‌کند.
5. آدرس اپ شما این خواهد بود: `https://<نام‌کاربری‌شما>.github.io/<نام‌مخزن>/`
6. روی گوشی اندرویدی همان آدرس را در Chrome باز کنید ← منو (⋮) ← **Add to Home screen** ← تمام؛ اپ با آیکون اختصاصی نصب می‌شود و بدون اینترنت هم کار می‌کند.

> **نکته:** اگر نام مخزن را `username.github.io` انتخاب کنید، در فایل `.github/workflows/deploy.yml` خط `NEXT_PUBLIC_BASE_PATH` را حذف کنید تا اپ در ریشه دامنه منتشر شود.

## اجرای محلی (اختیاری، برای توسعه‌دهندگان)

```bash
bun install        # یا npm install
bun run dev        # اجرای محیط توسعه روی http://localhost:3000
bun run build:static  # ساخت خروجی استاتیک (پوشه .next-export)
```

## ساختار پروژه

```
├── public/
│   ├── data/            # JSON های تولیدشده از دیتابیس (tests, cards, questions, ...)
│   ├── icons/           # آیکون‌های PWA
│   ├── manifest.json    # تنظیمات نصب اندرویدی
│   └── sw.js            # سرویس‌ورکر آفلاین
├── scripts/             # پارسر و مولد داده از فایل Word
├── src/
│   ├── app/             # لایه و صفحه اصلی (SPA با روتهش)
│   ├── components/      # پوسته اپ، ویوها و رندرکننده بخش‌ها
│   ├── fonts/           # وزیرمتن
│   └── lib/             # لایه داده، روتینگ، استور (Zustand)، موتور لایتنر و آزمون
└── .github/workflows/   # اکشن انتشار خودکار روی GitHub Pages
```

## منابع علمی دیتابیس

محتوای مطالب بر اساس یک دیتابیس جامع آزمایش‌های تشخیصی گردآوری شده است که کتاب‌هایی مانند «تست‌های تشخیصی و آزمایشگاهی پاگانا (۲۰۱۹)»، «اطلاعات جامع آزمایش‌های تشخیص طبی»، «آنالیز آزمایشگاهی ادرار و مایعات بدن دکتر گل‌افشان» و... در آن به کار رفته است. فهرست کامل منابع داخل خود اپ (بخش «درباره») قابل مشاهده است.

## سلب مسئولیت

این اپ صرفاً جنبه آموزشی دارد و جایگزین استانداردهای کاری، پروتکل‌های مرکز درمانی یا تصمیم‌گیری بالینی نیست. مقادیر مرجع ممکن است بسته به روش آزمایش و جمعیت مورد بررسی متفاوت باشد.
